# Phoenvo React Landing Page

A modern, responsive SaaS landing page built with **React** and **Vite**, following a **mobile-first** approach. This project showcases reusable React components, responsive design principles, and frontend best practices, with a focus on accessibility, SEO, and performance.

🌐 **Live Demo:** https://phoenvo-react-landing-page.vercel.app/

📂 **GitHub Repository:** https://github.com/Ndudiri-Chinaza/phoenvo-react-landing-page

---

## 📖 Overview

Phoenvo is a responsive landing page designed to present a modern SaaS product with a clean, engaging, and user-friendly interface. The application demonstrates component-based architecture, reusable UI design, and responsive layouts built with React.

## 🧩 Project Structure

The application is organized into reusable React components to improve maintainability and scalability.

### Components

- **Navbar** – Displays the logo, navigation links, authentication buttons, and responsive mobile menu.
- **Hero** – Introduces the product with a headline, description, call-to-action buttons, and dashboard preview.
- **FeatureCard** – A reusable component that displays individual product features.
- **TestimonialCard** – A reusable component that displays customer testimonials.
- **CTASection** – Encourages users to get started with a compelling call-to-action.
- **Footer** – Displays company information, navigation links, and social media icons.

---

## 🔄 Props Usage

Props were used throughout the application to build reusable and maintainable components.

Examples include:

- **Hero** receives:
  - Title
  - Description
  - Button text

- **FeatureCard** receives:
  - Feature icon
  - Feature title
  - Feature description

- **TestimonialCard** receives:
  - Customer image
  - Customer name
  - Customer role
  - Testimonial

- **CTASection** receives:
  - Heading
  - Description
  - Button text
  - Illustration

Using props allowed components to be reused with different content, reducing duplication and making the application easier to maintain.

## 📱 Responsive Design

The project follows a **mobile-first** development approach.

Layouts were progressively enhanced for:

- Mobile devices
- Tablets
- Laptops
- Desktop screens

Flexbox and CSS media queries were used to create responsive layouts across different screen sizes.

---

## ⚡ Performance & Optimization

During development, the project was optimized by:

- Converting large PNG images to WebP
- Resizing oversized images before compression
- Running Lighthouse audits
- Testing production builds using:

```bash
npm run build
npm run preview
```

These optimizations improved the application's loading performance and overall user experience.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Ndudiri-Chinaza/phoenvo-react-landing-page.git
```

Navigate into the project folder:

```bash
cd phoenvo-react-landing-page
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
